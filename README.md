# Brain Tumor Detection Using MRI Images

## 📌 Project Description

This project is an AI-based Brain Tumor Detection system that uses MRI images to predict the type of brain tumor.

The system uses a Convolutional Neural Network (CNN) trained on MRI images.

## 🧠 Tumor Classes

The model can classify MRI images into four categories:

- Glioma
- Meningioma
- Pituitary
- No Tumor

## 🛠️ Technologies Used

- Python
- TensorFlow
- Keras
- NumPy
- Pillow
- Streamlit
- CNN
